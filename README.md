# rshacudevidro.github.io

The not-found page for every site under this address, plus a fix for GitHub Pages matching project paths by exact case.

- **Any spelling reaches the site.** `/LARPERCORD/` and `/TeLinha/` go to `/larperCord/` and `/telinha/`, deep links included. `404.html` has a short list of sites that redirects without using the network; any other project with Pages is found through the GitHub API, so new sites need no change here.
- **The 404 is a terminal.** Try `help`, `ls`, or `cd <site>`.
